# Activity 5 – Step 1: Without examples (zero-shot)

**Chatbot / model:** ChatGPT (GPT-6.1 Sol)

## Prompt

```text
You are a software tester. Write 6 test ideas for the password rules delimited by three hashes. Use our team's test idea format.
###
A password must be 8 to 20 characters long and contain at least one digit and one uppercase letter.
###
```

## Response

I used **test idea → example → expected result** because your team’s template wasn’t included.

| # | Test idea | Example password | Expected result |
|---|---|---|---|
| 1 | Check one character below the minimum length, with both required character types present. | `Abcdef1` (7 characters) | Rejected |
| 2 | Check the minimum length with exactly one digit and one uppercase letter. | `Abcdefg1` (8 characters) | Accepted |
| 3 | Check the maximum length with exactly one digit and one uppercase letter. | `Abcdefghijklmnopqrs1` (20 characters) | Accepted |
| 4 | Check one character above the maximum length, with both required character types present. | `Abcdefghijklmnopqrst1` (21 characters) | Rejected |
| 5 | Check a password of valid length with an uppercase letter and no digits. | `Abcdefghij` | Rejected |
| 6 | Check a password of valid length with a digit and no uppercase letters. | `abcdefghi1` | Rejected |
