# Activity 5 – Step 2: With examples (few-shot)

**Chatbot / model:** ChatGPT (GPT-6.1 Sol)

## Prompt

```text
You are a software tester. Write 6 test ideas for the password rules delimited by three hashes. Use our team's test idea format.
###
A password must be 8 to 20 characters long and contain at least one digit and one uppercase letter.
###
For example:
* [BVA] 7 characters, one below the minimum ("Secret1") → rejected
* [EP] no digit ("SecretPass") → rejected
```

## Response

* [BVA] 7 characters, one below the minimum ("Secret1") → rejected
* [BVA] 8 characters, at the minimum ("Secrets1") → accepted
* [BVA] 20 characters, at the maximum ("SecretPassSecret1234") → accepted
* [BVA] 21 characters, one above the maximum ("SecretPassSecret12345") → rejected
* [EP] Valid length and uppercase letters, no digit ("SecretPass") → rejected
* [EP] Valid length and a digit, no uppercase letter ("secretpass1") → rejected
